# Campus Connect
CampusConnect is a lightweight PHP-based web application for managing student activities, academics, events, and assignments. It includes both student and admin interfaces with authentication, profile management, and file submission functionality.

## Features
### For Students : 
- User registration and login
- Profile management
- View academics, events, and community resources
- Event registration
- Assignment submission 

### For Admins : 
- Manage users
- View submitted assignments
- Manage resources and notifications
- Assign admin badges and roles 

## Technologies Used
- PHP 8+
- MySQL
- HTML5, CSS3, Bootstrap 5.3
- JavaScript (AJAX for event registration and file uploads) 

## Installation
1. Clone the repository 
2. Set up the web server 
3. Configure database connection
4. Run
